# 4. Gate 4.1 — Password 实现路线摘要

当前密码路线已经冻结为：

```text
User
→ 保存 PasswordData

PasswordData
至少包含：
algorithm
iterations
saltHex
hashHex
```

密码算法：

```text
PBKDF2-HMAC-SHA256
```

默认参数：

```text
salt
→ 16 bytes secure random

iterations
→ 600000

derived hash
→ 32 bytes

persistence
→ hexadecimal text
```

每次：

```text
创建账号
修改密码
管理员重置密码
```

都：

```text
生成全新 salt
重新派生
生成新 PasswordData
```

禁止：

```text
明文密码
std::hash(password)
MD5
单次 SHA-256
固定 salt
rand() salt
可逆加密密码
```

职责：

```text
PasswordHasher
→ hash / verify

AuthenticationService
→ 登录认证流程

UserManagementService
→ 创建账号 / 改密 / 重置

UserRepository
→ PasswordData 持久化
```

# 5. Gate 4.2 — Repository / Query / Statistics / Ranking 摘要

Repository 长期权威内存结构继续采用：

```text
std::vector<T>
```

不维护：

```text
vector + unordered_map
vector + map
```

双重长期索引。

基础算法：

```text
ID 查询
→ std::find_if
→ O(n)

多条件筛选
→ 一次线性扫描
→ O(n)

计数
→ std::count_if

批量条件删除
→ std::remove_if + erase

排行榜
→ std::sort
```

单 Student：

```text
score
duration
recordCount
```

必须：

```text
一次 VolunteerRecord 扫描同时累计
```

全体 Student 统计：

```text
StatisticsService
↓
一次扫描 VolunteerRecord
↓
临时 unordered_map<accountId, Aggregate>
```

这里的：

```text
unordered_map
```

只是函数内部临时工作区：

```text
不是 Repository
不持久化
不是第二份权威状态
```

排行榜目标复杂度：

```text
O(R + S log S)
```

禁止：

```text
每个 Student 各自重新扫描所有 records
→ O(S × R)
```

# 6. Gate 4.3 — Persistence / Recovery 摘要

所有权威文件禁止直接：

```text
truncate official file
```

单文件：

```text
serialize full state
↓
write same-directory .tmp
↓
flush / close
↓
prepare success
↓
old official → .bak
↓
.tmp → official
↓
success
↓
cleanup .bak
```

多文件：

```text
validate
↓
authorize
↓
determine affected repositories
↓
snapshot before first mutation
↓
mutate memory
↓
append OperationLog if required
↓
Prepare ALL
↓
全部成功后
Commit in deterministic order
```

Prepare 任一失败：

```text
NO COMMIT
↓
restore snapshot
↓
cleanup tmp
↓
PersistenceFailure
↓
系统可继续
```

如果：

```text
至少一个正式文件已 Commit
后续 Commit 失败
```

则：

```text
SeverePartialCommit
```

此时：

```text
禁止只恢复内存然后继续
禁止伪装成数据库事务
禁止复杂自动跨文件 rollback
```

应用进入：

```text
fatal persistence state
```

并：

```text
禁止后续普通写业务
引导安全退出 / 重启
```

OperationLog：

```text
与主业务同一提交单元
一起 Prepare
原则上最后 Commit
```

启动时：

```text
不自动提升 .tmp
不自动 fallback .bak
```

PersistenceCoordinator：

```text
只处理运行期提交
不参与启动 Load
不是 Unit of Work
不是 ACID transaction manager
```

# 12. Gate 4.6 — Result / Error / Fatal 摘要

最终：

```cpp
enum class ServiceError {
    None,
    ValidationFailed,
    BusinessRuleViolation,
    PermissionDenied,
    NotFound,
    PersistenceFailure,
    SeverePartialCommit
};
```

`None`：

```text
唯一成功状态
```

---

## Result<T>

概念：

```cpp
template <typename T>
class Result {
private:
    ServiceError error_;
    std::string message_;
    std::optional<T> value_;
};
```

成功不变量：

```text
error == None
value exists
```

失败不变量：

```text
error != None
value absent
message 非空
```

统一构造：

```text
success(T)
failure(error, message)
```

禁止：

```text
public default constructor
任意字段组合 constructor
```

---

## value()

只有成功时允许调用。

失败时：

```text
std::optional::value()
↓
std::bad_optional_access
```

统一行为。

不：

```text
返回 T{}
```

不同时再建立 assert 作为另一套正式行为。

---

## OperationResult

无成功业务值：

```text
OperationResult
```

有成功业务值：

```text
Result<T>
```

禁止：

```text
Result<void>
Result<OperationResult>
Result<Result<T>>
OperationResult + out parameter
```

---

## Expected failure

```text
ValidationFailed
BusinessRuleViolation
PermissionDenied
NotFound
PersistenceFailure
```

通过：

```text
Result / OperationResult
```

返回。

---

## Fatal / exceptional

例如：

```text
成功 Result 没 value
Approved Record 没 finalScore
Ready 后出现重复 stable ID
理论不可能 enum 状态
```

属于：

```text
programming error / broken invariant
```

走：

```text
exceptional / fatal path
```

不伪装成普通业务错误。

---

## SeverePartialCommit

虽然通过：

```text
ServiceError
```

返回当前调用结果，但同时：

```text
Application
→ fatal persistence state
```

后续普通写业务禁止继续。
